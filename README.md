# PC Builder – Frontend

React + TypeScript + Vite frontend for the PC Builder web application, developed as a university project.

**Backend repo:** https://github.com/SantyHdz/pc_builder

## Tech stack

- React and TypeScript
- Vite
- ESLint

## Run locally

```bash
git clone https://github.com/SantyHdz/pc_builder_front.git
cd pc_builder_front
npm install
npm run dev
```
